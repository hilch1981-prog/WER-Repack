# WER REPACK v1.1.1-rc.2 — 실행 사전 릴리즈 / Runnable prerelease

**2026-10-09 제작.** 19파일 안전성 개선을 새 auth/world에 반영하고 WER 버전·연구소명·제작일을 갱신했습니다. 동일 소스의 map/vmap/mmap 추출기, 깨끗한 초기 DB와 세 콘솔 실행기를 제공합니다. 게임 데이터와 전체 소스는 실행 ZIP에서 제외합니다. 소스는 같은 태그의 별도 자산입니다. 기존 v1.1.0 및 소스 전용 rc.1 자산은 보존합니다.

## 확인한 범위

- VS2022 x64 Release auth/world·네 추출기 링크, 여섯 x64 PE 형식·12,736개 빌드 소스 해시 일치, 18모듈 등록, 독립 Ollama 제외.
- 독립 WER 4DB 초기 SQL·한글·localhost TLS, 실제 월드 초기화.
- Windows PowerShell 5.1 첫 DB 설치와 재시작 보존, 한글·공백 폴더 설치/재시작.
- 매 SQL의 소유 listener PID·실제 데이터 폴더/포트 확인과13개 보호 회귀 시험. 한글 native 경로 바이트를 HEX+Windows ACP로 복원해 비교합니다.
- 최종 실행 파일의 Radmin 실제 프로토콜 **27/27 PASS**: 기본 admin/한글 realm1, 로그인/생성/재접속5, 장비·저장5, 이동5, 파티6, 거래5.
- auth/world의 실제 OpenSSL/MySQL DLL 경로, 시험 월드·MySQL 정상 종료.
- 20봇 축소 프로토콜 시험과 별도의 깨끗한 2,000봇 설정 시험을 구분했습니다. 후자는 250계정·2,500봇 캐릭터(랜덤 2,000+클래스 예비500)를 생성했으며, 마지막 표본은 온라인429·길드가입418·미가입11이었습니다. 커밋 여유가2GB 미만이 되어 자체 시험 서버만 안전 종료했습니다. 2,000봇 동시 온라인 통과는 아닙니다.
- 네 추출기의 소스 정의 Usage/누락 데이터 종료 조건을 확인했습니다. map 도구의 미지원 `-?`를 Usage로 오해했던 최초 시험은 정정 기록에 남깁니다. Windows 기본 CRT는 System32 경로·Microsoft 서명을 확인하며, OpenSSL/MySQL/MSVC 배포 DLL은 리팩 폴더 경로를 검증합니다.

AzerothGhost v1.0.8의 OS FourCC 앞쪽 NUL 인증 거부를 **시험 사본에서만** 끝문자 배치로 보완했습니다. Warden/서버 인증 검사를 끄지 않았습니다. 최초 실패와 통과 결과를 구분해 보존합니다.

## 확인하지 않은 범위

2,000봇 설정 시험은 시작 커밋 여유8,446MiB에서 진행했지만 리소스 보호 조건으로 중단했습니다. 생성된 DB와 실패 로그는 보존했으며 재초기화하지 않습니다. 다음 시험은 시작 여유16,384MiB 이상을 확인한 뒤 재개할 계획이고, 이 값도 충분한 서버 용량을 보증하는 수치는 아닙니다. 배포의 시작 보호8192MB는 최소 시작 조건일 뿐 2,000봇 운영 권장량이 아닙니다. 2,000봇 동시 온라인·지속 부하는 아직 미검증입니다.

빌드 중 메모리 오류와 자원 회복 후 최종 링크 통과는 구분합니다. 그래픽 클라이언트, 다른 PC의 Radmin 접속, 실제 외부 LLM, 모든 레이드/퀘스트/PvP, 모든 사용자 MPQ 전체 재추출을 완료했다고 주장하지 않습니다. BWL 이동/어그로, 잔여 영어, Dalaran 메모리 오류와 재접속 Unknown은 별도 추적 대상입니다. item duration flag·누락 challenge-mode script·펫waypoint0·일부 봇 길드가입 실패 경고도 미해결로 기록합니다.
