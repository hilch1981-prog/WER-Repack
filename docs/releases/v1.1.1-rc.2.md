# WER REPACK v1.1.1-rc.2 — 실행 사전 릴리즈 / Runnable prerelease

**2026-10-09 제작.** 19파일 안전성 개선을 새 auth/world에 반영하고 WER 버전·연구소명·제작일을 갱신했습니다. 동일 소스의 map/vmap/mmap 추출기, 깨끗한 초기 DB와 세 콘솔 실행기를 제공합니다. 게임 데이터와 전체 소스는 실행 ZIP에서 제외합니다. 소스는 같은 태그의 별도 자산입니다. 기존 v1.1.0 및 소스 전용 rc.1 자산은 보존합니다.

## 확인한 범위

- VS2022 x64 Release auth/world 링크, 18모듈 등록, 독립 Ollama 제외.
- 독립 WER 4DB 초기 SQL·한글·localhost TLS, 실제 월드 초기화.
- Windows PowerShell 5.1 첫 DB 설치와 재시작 보존, 한글·공백 폴더 설치/재시작.
- 매 SQL의 소유 listener PID·실제 데이터 폴더/포트 확인과13개 보호 회귀 시험. 한글 native 경로 바이트를 HEX+Windows ACP로 복원해 비교합니다.
- Radmin 실제 프로토콜 **26/26 PASS**: 로그인/생성/재접속5, 장비·저장5, 이동5, 파티6, 거래5.
- auth/world의 실제 OpenSSL/MySQL DLL 경로, 시험 월드·MySQL 정상 종료.
- 20봇 축소 환경 생성과 길드 데이터. 2,000봇 분포·부하 검증은 아닙니다.

AzerothGhost v1.0.8의 OS FourCC 앞쪽 NUL 인증 거부를 **시험 사본에서만** 끝문자 배치로 보완했습니다. Warden/서버 인증 검사를 끄지 않았습니다. 최초 실패와 통과 결과를 구분해 보존합니다.

## 확인하지 않은 범위

호스트 커밋 여유가 8GiB 미만이라 2,000봇 지속 부하를 실행하지 않았습니다. 배포 설정은 Min/MaxRandomBots=2000입니다. 그래픽 클라이언트, 다른 PC의 Radmin 접속, 실제 외부 LLM, 모든 레이드/퀘스트/PvP, 모든 사용자 MPQ 전체 재추출을 완료했다고 주장하지 않습니다. BWL 이동/어그로, 잔여 영어, Dalaran 메모리 오류와 재접속 Unknown은 별도 추적 대상입니다. 기존 item duration flag와 누락 challenge-mode script 경고도 이번에 해결했다고 표시하지 않습니다.

## English

Runnable **Windows x64 prerelease**, built October 9, 2026. The 19-file safety update is included in new auth/world executables with current WER branding. Matching extraction tools, pristine bootstrap SQL and three foreground consoles are provided. Full source is a separate asset; no game client/extracted maps/DBC or operator API keys are redistributed. Existing v1.1.0 and source-only rc.1 assets are unchanged.

The isolated stack reached world readiness; **26 protocol tests passed** across login/relog, inventory/equipment persistence, teleport, parties and trading through Radmin. Actual loaded native DLL paths and world/MySQL graceful shutdown were checked. A test-only AzerothGhost v1.0.8 OS FourCC terminator correction fixed harness authentication; Warden/server authentication remained enabled.

Fresh installation and restart preservation were verified using Windows PowerShell 5.1, including a folder containing Korean characters and spaces. The bootstrap contains one administrator and an auction-house service account, with no pre-generated playerbots or user guilds.

Thirteen mocked SQL-safety regressions cover listener ownership, loopback binding, data-directory/port mismatch and Windows path encodings. Every real statement checks identity first; native path bytes are retrieved as HEX and decoded using the system ACP. No check was bypassed to pass Korean-folder installation.

Reduced **20-bot** initialization and guild data were observed. Shipped target is **2,000 bots**, but sustained load was not tested with host commit headroom below 8 GiB. Graphical gameplay, another-PC connectivity, live LLM, all raid/PvP scenarios and arbitrary client MPQ extraction are not certified. Existing warnings and gameplay/client issues remain separately tracked. Do not overwrite production folders/data directories.
