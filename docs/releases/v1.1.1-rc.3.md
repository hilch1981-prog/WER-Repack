# WER REPACK v1.1.1-rc.3 — 2026-10-10

**실행파일과 대응 전체 소스를 함께 제공하는 사전 릴리즈입니다.** 기존 v1.1.0 안정판과 rc.1/rc.2 자산은 교체하지 않습니다.

## 달라진 점

- 봇 길드를 만든 직후 이름 캐시를 갱신해 같은 이름을 다시 선택하는 문제를 방지합니다.
- 펫의 초기 이동 선택에서 일반 몬스터용 기본 이동 생성을 제외합니다.
- 누락된 `wl_equip_item_notice` 문구를 DB에 추가하며 koKR는 `text_loc1`에서 `%item_link 장비를 장착합니다.`를 읽습니다. 기존 사용자 문구는 덮어쓰지 않습니다.
- 아이템45280/46104의 duration=0과 충돌하는 정확한 custom flag=1만 정리합니다. 아이템 지급·기간 변경은 하지 않습니다.
- NPC entry16320/GUID82897의 경로가 실제로 없는 경우에만 이동형을 idle로 전환합니다. **순찰 경로 복원이나 다른 NPC 수정이 아닙니다.**
- 위 SQL은 MySQL/로그인 준비 과정에 연결했습니다. 파일 해시·InnoDB·리팩 전용 DB를 확인하고 한 트랜잭션으로 적용하며, 전후 대상 행과 결과를 `logs/migrations`에 기록합니다. 재시작해도 중복 삽입하지 않습니다.
- 2,000봇 목표는 유지합니다. 월드 시작 보호는 실제 `CommitLimit-CommittedBytes`를 사용하며 최소16,384MiB입니다. OS·페이지파일을 자동 변경하지 않습니다.

## 확인한 범위

- MSVC2022 x64 Release로 서버2종·추출기4종 **전체 링크 성공**. 공개 manifest의 코어 소스12,736파일과 실제 빌드 입력을 대조했습니다.
- Radmin 경유 실제 서버 프로토콜 **34시험 통과**: 기본 로그인·재접속·장비·순간이동·파티·거래27, 펫4, 길드3. soft-pass는 사용하지 않았습니다.
- 실제 격리 DB의 SQL 첫 적용1/2/1행, 두 번째 적용0/0/0행을 확인했습니다. 기존 후보의28개 SQL/rollback fixture 검사와6개 한국어 렌더링 검사는 별도 기록으로 유지합니다.
- 한글·공백 폴더의 실제 Windows PowerShell5.1 첫 설치·재실행도 모두 종료코드0입니다. 초기 시험에서 발견한 해시 명령 자동로드 의존성은 .NET SHA256으로 제거하고 새 사본에서 재검증했습니다. 재초기화·SQL 중복 변경은 없었습니다.
- 테스트 종료 후 월드 정상 저장·DB 정상 종료와 포트 정리를 확인했습니다. 개인 계정·키·테스트 DB·게임 데이터는 배포하지 않습니다.

**미검증:** 2,000봇 지속 동시 접속, 그래픽 클라이언트 전체 플레이, 실 외부 LLM, 모든 공격대·길드 기능. 길드3개 테스트는 전체 길드/은행 시스템 보증이 아닙니다. `gobject_challenge_modes` 미구현 binding 등 기존 별도 경고도 이번 수정으로 해결됐다고 주장하지 않습니다.
