## 한국어

[PR #1](https://github.com/hilch1981-prog/WER-Repack/pull/1)의 **19파일(16cpp/3h)** 개선과 영어 문서, 읽기 전용 소스 검사를 제공합니다.
레전드와 적용 모듈을 함께 검토했으며 원저자·라이선스·한글화·내부 설정 키를 보존했습니다.

| 분야 | 주요 변경 |
|---|---|
| Playerbots | 인벤토리 변경 전 값 보존, 은행 결과 판정, 장비 후보 GUID 재검사, 지연 명령 발신자 GUID/권한 확인 |
| Legends / 코어 | 동일 master 반복 초기화·인사 억제, 퀘스트 대상 및 오라 원시전자 null 방어 |
| Dungeon Clear | 전투 상태만 있고 공격하지 않는 리더 탱커의 실제 전투 합류 보조 |
| 경매 / 루팅 | AH 활성 획득 출처 OR 판정, AoE 소유권·분배·퀘스트 전체 수납 방어 |
| 길드하우스 | 신규 오브젝트 방향과 quaternion 일치 |

**장비 후보 변경은 예방 보강입니다.** Playerbots #2895는 병합 없이 닫혔고 원 작성자가 현재 경로의 crash 설명을 철회했습니다.
DC 변경은 어그로 배율이나 검은날개 둥지 전체 수정이 아니며 기존 오브젝트·운영 DB를 일괄 수정하지 않습니다.

### 다운로드 및 사용 범위

- **`WER_Source_v1.1.1-rc.1.zip`**: 이 태그의 공개 소스·빌드 안내·원본 라이선스·한국어/영어 문서·매니페스트·읽기 전용 검사기. 서버 실행용 ZIP이 아닙니다.
- **`RELEASE_MANIFEST.json`**: 태그 대응 커밋, 자산 크기/해시 및 검증 범위.
- **`SHA256SUMS.txt`**: 자산 SHA-256. 다운로드 후 비교하세요.
- 압축을 **새 폴더**에 풀고 루트에서 `python -B tools/verify-source-manifest.py`로 전체 12,736 소스 파일을 읽기 전용 검사합니다.
- 빌드는 별도 VS2022 C++/SDK/Boost/OpenSSL/MySQL 개발 환경이 필요합니다. [한국어 빌드 안내](https://github.com/hilch1981-prog/WER-Repack/blob/v1.1.1-rc.1/source/README.md).
- **기존 서버에 덮어쓰거나 DB를 초기화하지 마세요.** 소스 게시는 운영 배포가 아닙니다.

### 검증과 남은 사항

검증: 정/역 패치·소스 해시, 16/16 실제 TU 검사, 별도 VS2022 auth/world 전체 링크,
격리 MySQL UTF-8/ICU/TLS 암호화·정상 종료, 깨끗한 SQL 4개/538테이블 import, auth DB pool/한글 realm dry-run.
GitHub CI는 **7 회귀 시험 + 12,736 파일 해시 검사**이며 네이티브 서버 빌드나 배포 작업이 아닙니다.

**미검증:** 신규 수정본의 월드 전체 ready, 실제 클라이언트 접속, 게임 회귀, 2,000봇 장시간 부하, 실제 외부 LLM 호출.
기존 BWL/결투/축제 NPC/달라란/재접속 이름/잔여 영어·펫·길드 분포까지 해결 완료로 표시하지 않습니다.
OpenSSL/MySQL 보안 바이너리는 업그레이드하지 않습니다. 일부 제안은 test-staging 또는 미병합 PR에서 선별했으며 원본 안정판 전체 갱신이 아닙니다.

## English

> [!IMPORTANT]
> **Source-only prerelease, not a new runnable Windows repack.**
> Existing v1.1.0 executable ZIPs, tag and matching source ZIP are retained.
> Publishing does not deploy to production, change a DB/config, or add newly built server executables, database runtimes or extracted game data.

This release contains [PR #1](https://github.com/hilch1981-prog/WER-Repack/pull/1), a selective **19-file (16 C++ / 3 headers)** safety update,
plus Korean/English guides, preserved authors/licenses and read-only source-integrity checks.
Review covers both integrated modules and Legends source, not an indiscriminate upstream branch replacement.

Changes: inventory value snapshots, banking success accounting, defensive equipment GUID resolution, queued sender GUID/permission checks;
same-master reset/greeting suppression; quest/aura null guards; Dungeon Clear leader-tank combat assist;
AH acquisition-source OR logic; AoE ownership/distribution/full-capacity guards; new guild-object orientation/quaternion alignment.
Internal `WowLegends.*` keys, Korean localization and existing policies remain compatible.

**Do not label equipment changes a proven crash fix:** upstream #2895 was closed without merging and the author withdrew the current-path crash explanation.
DC is not a threat multiplier or complete BWL repair. No bulk production DB migration is included.

### Assets and use

- **`WER_Source_v1.1.1-rc.1.zip`**: source at this tag, original licenses, build guide, bilingual docs, manifests and read-only verifier. Not a newly built runnable server package.
- **`RELEASE_MANIFEST.json`**: matching commit, asset hashes/sizes and validation boundaries.
- **`SHA256SUMS.txt`**: SHA-256 checksums to compare after downloading.
- Extract into a **new folder**. At its root run `python -B tools/verify-source-manifest.py` to verify all 12,736 source files without building or starting anything.
- Building requires VS2022 C++/SDK/Boost/OpenSSL/MySQL dependencies. [English source/build guide](https://github.com/hilch1981-prog/WER-Repack/blob/v1.1.1-rc.1/source/README.en.md).
- **Do not overwrite an existing server or reinitialize its DB.** For the existing runnable package, use [v1.1.0](https://github.com/hilch1981-prog/WER-Repack/releases/tag/v1.1.0).

Passed separately: hashes/patch checks, 16 real translation units, full native auth/world linking,
isolated MySQL SQL/UTF-8/ICU/TLS encryption/shutdown, four clean dumps with 538 tables, auth DB-pool/Korean-realm dry-run.
GitHub CI runs **7 verifier regressions and 12,736-file integrity checks**, not a native build, game server or deployment.
**Not yet verified:** full world initialization, actual client login, gameplay regressions, sustained 2,000-bot load and live LLM calls.
Existing BWL/PvP/Brewfest/Dalaran/reconnect-name/English/pet/guild-distribution issues are not declared resolved.
Runtime security upgrades are not included; some changes were selectively adapted from test-staging/unmerged proposals.

**🟨 Try NVIDIA LLM bot chat on a separately validated runnable server.** Your own key is needed only for external chat, not ordinary bots/basic startup.
Hosted prototype availability/limits/terms apply; this is not an unlimited-free or uptime guarantee.
The config remains `configs/modules/mod_wowlegends.conf`, key `WowLegends.AiChat.ApiKey`.
No keys are supplied, and no paid calls were made for this release.
