# WER REPACK_VER.1.0.0

와우 에뮬레이터 연구소 — Windows x64 / WoW 3.3.5a (12340) 한국어 클라이언트용

## 처음 실행

1. ZIP 전체를 쓰기 가능한 로컬 폴더에 풉니다. 예: `C:\WER\WER REPACK_VER.1.0.0`. **한글·공백 경로도 실행기 개정2에서 검증했습니다.** 압축파일 내부, Program Files 같은 쓰기 제한 폴더에서는 실행하지 마세요. 짧은 경로를 권장하며 모든 특수문자·네트워크 경로를 검증한 것은 아닙니다.
2. `scripts/settings.json`에서 포트를 확인합니다. 기본 MySQL `3306`(localhost만), 인증 `3724`, 게임 `59823`. 다른 리팩/서버가 사용 중이면 실행기가 중단합니다. 기존 서버를 종료하거나 설정을 바꾸지 않습니다.
3. 처음 켜기 전에 `DbPassword`를 본인만 아는 영문/숫자/하이픈/밑줄 12~80자로 바꾸는 것을 권장합니다. 기본값은 공개 배포용이며 운영 서버 비밀번호가 아닙니다. 설치 완료 뒤에는 이 값만 바꾸지 마세요. DB 사용자 비밀번호도 함께 변경해야 합니다.
4. **`00_WER_실행메뉴.bat` 또는 `start.bat`**을 실행하고 **4번 전체 서버 시작**을 선택합니다. 처음에는 DB를 초기화하고 4개 덤프를 가져온 뒤 서버가 봇을 새로 만듭니다. 완료 전 창을 닫지 마세요. **5번 서버 상태**에서 월드 서버와 렐름의 접속 준비 완료를 확인합니다. 단계별로 시작하려면 1번 MySQL → 2번 로그인 → 3번 월드 순서로 선택하세요.
5. 클라이언트 `Data\koKR\realmlist.wtf`: 로컬 접속이면 `set realmlist 127.0.0.1`. 계정 **admin / admin**, GM 3. 인터넷/VPN에 개방하기 전에 반드시 비밀번호를 변경하세요.

## 포함 데이터와 첫 실행 봇

- 배포 덤프의 로그인 계정은 ADMIN 1개뿐이며 게임 캐릭터·플레이 기록·길드 소유권·경매·아이템·개인 대화 기억은 비어 있습니다.
- 첫 설치 때 경매 기능 전용 `WER_AHBOT` 계정/`경매관리인` 캐릭터를 새로 준비합니다. GM 권한이 없으며 로그인용 비밀번호를 배포하지 않습니다. 기존 운영 경매 캐릭터를 복사하지 않았습니다.
- 플레이봇은 서버 첫 부팅 때 새로 생성합니다. 목표 온라인 봇 수는 **2,000**, `RandomBotAccountCount=0`은 현행 소스에서 필요한 계정 수 자동 계산입니다. 계정 수와 온라인 봇 수는 같은 값이 아닙니다.
- 봇 전용 길드는 최대 40개, 길드당 최대 25명(총 수용 상한 약 1,000명). 진영에 맞춰 자동 가입하며 나머지 봇은 무소속으로 남습니다. 사용자 길드는 봇 자동 가입 대상으로 삼지 않습니다. 실제 접속 비율은 로그인/생성 순서에 따라 달라집니다.
- 한국어 봇/길드/투기장 이름 사전, 기존 대사 5,706행, 월드 콘텐츠·로케일·경매 설정을 보존합니다. 첫 부팅은 일반 재시작보다 오래 걸리며 RAM/CPU 여유에 따라 속도가 달라집니다.
- 운영 테스트 계정, 사용자 캐릭터, 운영 API 키, 채팅 기억/로그는 포함하지 않습니다.

## 외부 LLM

`configs/modules/mod_wowlegends.conf`의 `WowLegends.AiChat.ApiKey`에 **본인의 키**를 입력한 뒤 서버를 다시 켭니다. 기존 공급자/모델/대화 정책은 유지했지만 키는 비워 두었습니다. 키 없이 외부 LLM이 응답한다고 보장하지 않습니다. 외부 API 과금은 사용자 계정에 발생합니다.

기본 와우 `/1`, `/s`, 귓속말, 파티/공대/길드 대화 정책을 계승했습니다. 별도 `.world` 모드는 필요하지 않으며 `mod-enhanced-worldchat`은 비활성 상태입니다. 한국어 보완이 포함되지만 모든 상황에서 영문 0건을 검증한 것은 아닙니다.

## Radmin / 외부 접속

`RealmAddress="auto"`는 Radmin 어댑터의 `26.*` 주소가 있으면 그 주소를 사용하고, 없으면 로컬 `127.0.0.1`을 사용합니다. 운영자의 기존 Radmin IP를 다른 PC에 하드코딩하지 않았습니다. 외부 접속자에게는 **이 리팩을 실행하는 PC의 Radmin IP와 계정**을 전달하세요. 같은 Radmin 네트워크 가입과 게임/인증 포트 방화벽 허용이 별도로 필요합니다. MySQL 포트를 외부에 개방하지 마세요.

직접 IP/도메인을 지정하려면 `scripts/settings.json`의 `RealmAddress`를 바꿉니다. NAT 공인망 접속은 포트 전달이 추가로 필요하며 리팩이 공유기나 방화벽을 임의 변경하지 않습니다.

## 시작·종료·오류 로그

- `00_WER_실행메뉴.bat` / `start.bat`: 한글 통합 메뉴. **0번은 메뉴 창만 닫으며 서버를 끄지 않습니다.**
- `01_MySQL_시작.bat` / `_Start_MySQL.bat`: MySQL만 시작. 첫 설치이면 초기 DB 가져오기 포함.
- `02_로그인서버_시작.bat` / `_Start_AuthServer.bat`: MySQL을 확인하고 로그인 서버만 시작.
- `03_월드서버_시작.bat` / `_Start_WorldServer.bat`: 필요한 MySQL·로그인 서버를 먼저 확인하고 월드를 추가 시작.
- `04_전체서버_시작.bat` / `_Start_Server.bat`: MySQL → 로그인 → 월드 순서로 전체 시작. 이미 실행 중인 동일 폴더 서버는 중복 시작하지 않습니다.
- `05_서버상태_확인.bat` / `_Status.bat`: 이 폴더 소유 PID·포트·렐름 접속 준비 상태.
- `06_오류로그_확인.bat` / `_Logs.bat`: 최근 월드/로그인/MySQL/자동복구 오류 로그 확인.
- `07_월드서버_종료.bat` / `_Stop_WorldServer.bat`: 월드만 저장 후 정상 종료, 로그인·MySQL 유지.
- `08_로그인서버_종료.bat` / `_Stop_AuthServer.bat`: 로그인만 종료. 월드가 실행 중이면 먼저 월드를 종료하라는 안내 후 거절합니다.
- `09_MySQL_종료.bat` / `_Stop_MySQL.bat`: 게임 서버가 모두 종료된 뒤 MySQL 정상 종료. 실행 중 DB 강제 종료는 하지 않습니다.
- **`10_전체서버_종료.bat` / `_Stop_Server.bat`: 월드 저장·종료 → 로그인 → MySQL까지 전체 종료.** 구 개정1의 `_Stop_Server`는 DB를 남겼지만 개정2는 원본 리팩과 동일하게 전체 종료합니다.
- 각 배치는 성공/오류 내용을 읽을 수 있도록 키 입력을 기다립니다. 자동화는 `--no-pause`, 서버를 시작하지 않는 파일/포트 설정 점검은 `--check`를 사용하세요. `_Check.bat --check`도 가능합니다.
- 서버는 숨김 백그라운드 프로세스로 실행됩니다. 개별 EXE를 직접 더블클릭하지 말고 메뉴/배치를 사용하세요. 오류는 6번 로그와 `logs/console-*.err.log`에서 확인합니다.
- 월드/인증 프로세스 종료 시 자동 재시작. 월드 반복 종료 5회면 무한 재시작을 멈추고 오류 확인을 요구합니다. MySQL이 종료되면 이 폴더의 인스턴스만 복구를 시도합니다. OS 재부팅 때 자동 시작하는 Windows 서비스/예약 작업은 설치하지 않습니다.
- **월드 시작 시** Windows의 남은 커밋 메모리를 검사하며 기본 8GB 이상을 요구합니다. 로그인·MySQL만 시작할 때는 이 월드용 제한을 적용하지 않습니다. 물리 RAM 여유와 커밋 여유는 다릅니다. 이 조건은 2,000봇 장시간 안정성을 보증하는 수치가 아니라 최소 시작 보호 장치입니다.
- `logs/Errors.log`, `logs/mysql-error.log`, `logs/watchdog.log`, `logs/console-*.err.log`를 보관하세요. 이전 Server.log는 재시작 시 별도 보존합니다.

## 구성

루트 실행파일/DLL, `configs`, `data`(dbc/maps/vmaps/mmaps), `modules`(모듈 SQL), `dump`(깨끗한 초기 DB), `mysql`(8.4.9 portable), `전용애드온`, `scripts`, `docs`, `source`, `licenses`.

`mysql/data`는 첫 실행 때 새로 만들어집니다. 이미 사용 중인 폴더에 덮어 설치하거나 `dump`를 기존 운영 DB에 강제로 가져오지 마세요. 백업은 정상 종료 후 해당 리팩 폴더 전체를 보존하는 방식이 가장 단순합니다. 기본 설정에는 자동 SQL 업데이트를 꺼 두었습니다.

클라이언트 본체는 포함하지 않습니다. 전용애드온 원본 MultiBot 분할 ZIP은 `.zip`과 `.z01`을 같은 폴더에 두고 호환 압축 프로그램으로 풉니다. 애드온 설치는 선택 사항입니다.
