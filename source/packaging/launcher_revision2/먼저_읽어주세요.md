# WER REPACK_VER.1.0.0 — 실행기 개정2

압축을 모두 푼 후 **00_WER_실행메뉴.bat** 또는 **start.bat**을 실행하세요.

- 처음 시작: 메뉴 **4번 전체 시작**. MySQL 설치 → 로그인 → 월드 순서로 자동 처리합니다.
- 개별 시작: **1번 MySQL → 2번 로그인 → 3번 월드**.
- 준비 확인: **5번 상태 확인**, 문제 확인: **6번 오류 로그**.
- 전체 종료: 메뉴 **A**, 또는 **10_전체서버_종료.bat**. 데이터를 저장하고 MySQL까지 종료합니다.
- 메뉴 **0번은 창만 닫습니다. 서버는 계속 실행됩니다.**

서버는 백그라운드로 실행됩니다. `authserver.exe` / `worldserver.exe`를 직접 실행하지 마세요.

한글·공백 폴더도 지원합니다. 실행 권한이 있는 짧은 로컬 폴더에 풀고, ZIP 내부나 쓰기 제한 폴더에서는 실행하지 마세요.

기본 계정은 **admin / admin**입니다. 외부 공개 전에 비밀번호를 바꾸세요. 외부 LLM API 키는 포함하지 않습니다.

첫 월드 시작은 봇 생성으로 오래 걸릴 수 있습니다. **종료 후 재시작한다고 DB를 다시 초기화하지 않습니다.** 오류가 나도 `mysql/data`를 삭제하지 마세요.

포트·접속·봇·길드·종료·로그의 상세 설명은 **QUICKSTART.md**를 보세요.
