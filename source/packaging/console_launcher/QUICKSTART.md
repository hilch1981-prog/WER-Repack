# WER REPACK_VER.1.0.0 사용 안내

## 실행은 3개만

ZIP을 새 로컬 폴더에 모두 풀고 순서대로 더블클릭하세요.

1. **1_MYSQL.bat** — MySQL을 시작합니다. 첫 설치만 DB 4개를 자동으로 가져옵니다. `ready for connections` 표시 후 다음으로 진행합니다.
2. **2_AUTHSERVER.bat** — 로그인 서버를 시작합니다.
3. **3_WORLDSERVER.bat** — 월드 서버를 시작합니다. 처음에는 봇 생성으로 오래 걸릴 수 있습니다.

**3개 콘솔 창을 열어 둔 채 게임에 접속하세요.** 메뉴, 백그라운드 감시, 자동 재시작은 없습니다. 개별 EXE 대신 이 3개 배치를 쓰면 설정 경로와 DB 설치 준비가 맞춰집니다. 다른 서버를 자동으로 시작하지 않으며 중복 실행/잘못된 순서는 안내 후 중단합니다.

종료는 **월드 → 로그인 → MySQL** 순서입니다. 각 창에서 **Ctrl+C**를 누른 뒤 해당 서버가 끝난 것을 확인하고 다음 서버를 종료합니다. 배치 종료 확인이 뜨면 Y를 입력하세요. 월드의 DB 저장 완료 전에 MySQL을 끄지 마세요. 창 X/작업관리자 강제 종료는 피하세요.

한글·공백 경로에서 기동을 확인했습니다. 짧은 로컬 폴더를 권장하며 ZIP 내부, 쓰기 제한 폴더, 네트워크 드라이브는 피하세요. 일반 사용을 위해 메뉴 옵션이나 명령어를 외울 필요가 없습니다.

## 접속

- 기본 계정 **admin / admin**, GM3. 외부 공개 전에 비밀번호를 바꾸세요.
- 로컬 클라이언트 `Data/koKR/realmlist.wtf`: `set realmlist 127.0.0.1`.
- 기본 포트: MySQL3306(localhost 전용), 로그인3724, 월드59823. 변경이 필요할 때만 `scripts/settings.json`을 편집합니다.
- Radmin: RealmAddress=auto는 이 PC의 Radmin26.* 주소를 찾아 사용하고 없으면127.0.0.1을 씁니다. 외부 이용자는 같은 Radmin 네트워크에 가입하고 운영자 PC의 Radmin IP로 접속합니다. 로그인/게임 방화벽 허용은 별도이며 MySQL을 외부 개방하지 마세요.
- DB 비밀번호는 첫 설치 전에만 settings.json의 DbPassword를 영문·숫자·하이픈·밑줄12~80자로 변경할 수 있습니다. 설치 뒤에는 DB 사용자 비밀번호도 함께 바꾸어야 하므로 설정값만 바꾸지 마세요.

## 포함 데이터

- 초기 DB의 로그인 계정은 ADMIN뿐입니다. 사용자 캐릭터·아이템·경매·길드 소유권·대화 기억은 비어 있습니다.
- 처음 실행할 때 경매 서비스용 WER_AHBOT/경매관리인과 랜덤봇을 새로 만듭니다. 기존 운영 사용자의 계정·캐릭터·개인 데이터는 복사하지 않았습니다.
- 목표 온라인 봇2000. RandomBotAccountCount=0은 자동 계산입니다. 봇 길드는 최대40개×25명, 일부는 무소속. 전체 봇 강제 길드 가입이 아닙니다.
- 한국어 정적 DB/봇 이름/길드/대사5706행 및 현행 콘텐츠·경매 설정 유지.
- 월드 시작 최소 커밋 여유8GB 보호검사. 2000봇 장시간 안정성을 보증하는 수치가 아닙니다.
- 기존 mysql/data는 재시작해도 초기화하지 않습니다. 오류가 나도 삭제하지 마세요. 정상 종료 후 리팩 폴더 전체를 백업하세요.

## 외부 LLM

API 키는 포함하지 않습니다. `configs/modules/mod_wowlegends.conf`의 `WowLegends.AiChat.ApiKey`에 본인 키를 넣고 월드 서버를 재시작하세요. 외부 과금은 본인 계정에 발생합니다. 기본 `/1`, `/s`, 귓속말/파티/공대/길드 정책은 유지하며 별도 `.world` 모드는 필요하지 않습니다. enhanced-worldchat은 비활성입니다.

## 오류/검증/출처

오류는 각 콘솔 창과 `logs/Errors.log`, `logs/AuthErrors.log`, `logs/mysql-error.log`에서 확인하세요. 초기화 준비 이력의 `logs/watchdog.log`라는 파일명은 이전 실행기에서 유지된 이름일 뿐, 이 버전에서는 자동복구 감시 프로세스를 실행하지 않습니다. 서버가 내려가면 원인을 확인하고 해당 배치를 다시 실행합니다.

실행기 콘솔3개 표시/축소봇 기동/순서대로 Ctrl+C 정상 종료를 실제 검증했습니다. 처음 DB 설치의 준비 단계만 임시 MySQL 프로세스로 자동화하며, 준비가 끝나면 그 프로세스를 정상 종료하고 같은 배치 창의 콘솔 MySQL로 전환합니다. 게임 운영은 숨김 프로세스를 사용하지 않습니다.

게임 실행파일·DB·configs는 이번 실행방식 변경으로 바꾸지 않았습니다. 사용자가 보류한 Individual Progression 및 미완료 BWL 문제를 해결한 것으로 표시하지 않습니다. 2000봇 부하/모든 레이드/새PC 외부 게임접속/LLM실호출은 별도 검증입니다.

전체 소스는 `source/WER_Source.zip`, 원 라이선스는 `licenses` 및 각 모듈에 보존합니다. 클라이언트 본체는 미포함이며 `전용애드온`은 선택 사항입니다. 배포 파일 해시는 SHA256SUMS.txt, 게임 제한은 docs/RELEASE_NOTES.md, 현재 실행기 검증은 docs/CONSOLE_LAUNCHER.json을 보세요. 이전 개정2 메뉴 안내는 더 이상 사용하지 않습니다.
