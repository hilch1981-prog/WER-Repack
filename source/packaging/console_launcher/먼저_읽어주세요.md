# WER REPACK_VER.1.0.0

압축을 모두 풀고 **아래 3개를 순서대로 실행하세요.**

1. **1_MYSQL.bat** — DB 시작. 처음 한 번은 자동 설치합니다.
2. **2_AUTHSERVER.bat** — 로그인 서버 시작.
3. **3_WORLDSERVER.bat** — 월드 서버 시작. 처음에는 봇 생성 때문에 시간이 걸립니다.

**3개 콘솔 창을 켜 둔 채 게임에 접속하면 됩니다. 메뉴·백그라운드 감시·자동 재시작은 없습니다.**

종료는 반대로 **월드 → 로그인 → MySQL** 순서입니다. 각 창에서 **Ctrl+C**를 누르고 해당 서버의 종료가 끝난 것을 확인한 다음 다음 창을 종료하세요. 창을 강제로 닫거나 작업관리자로 죽이지 마세요. 배치 종료 확인이 뜨면 Y를 입력합니다.

기본 계정: **admin / admin**. 외부 공개 전에 비밀번호를 변경하세요.

첫 설치 후 DB는 그대로 유지됩니다. `mysql/data`를 삭제하지 마세요. 한글·공백 폴더 사용 가능, 압축파일 내부에서는 실행하지 마세요.

외부 API 키는 미포함입니다. 접속·키·설정 설명이 필요할 때만 **QUICKSTART.md**를 보세요.
