# WOW Legends 로컬 이식 사본

- 원본: VenomekPL/mod-all-flightpaths, 공식 master `32df51494eecb7d8203fa5c1b64f8b786ad58e2d`.
- 원본 커밋: 2026-07-23 04:34:37 KST.
- 로컬 작업일: 2026-09-15. 로컬 패치 식별자 `wl-ko1`(공식 릴리스 버전이 아님).
- 아직 Integration에 추가하지 않았고 C++ 전체 컴파일/링크/실게임 검증 전이다.

원본 코드/README 확인: 로그인 시 원래 진영의 taxi mask를 사용해 비행 지점을 개방하며 SQL은 없다. 코어의 GetTeamId(true), m_taxi.SetTaximaskNode, 진영별 마스크 API와 대조했다. 정상 캐릭터 저장 시 taximask가 영구 저장될 수 있으므로 진행 정책과 충돌 여부를 먼저 시험한다.

로컬 변경:

1. 설정 파일과 코드 기본값을 모두 비활성으로 통일했다.
2. 로그인 안내만 koKR 세션에서 한국어로 표시한다. 다른 언어 원문 유지.
3. 로그인 null player/session 방어. taxi mask 인덱스에 uint32를 사용해 uint8로의 조기 축소를 피한다.

이후 검증: 실제 WOW 헤더로 컴파일 → 분리 캐릭터로 진영별/공용/상대 진영 마스크 비교 → 비활성 로그인 무변경 → 재로그인/저장 확인 → 개인진행 정책과 함께 활성 여부 결정. 모듈 폴더 추가만으로 모든 사용자의 비행 경로를 개방하지 않는다.
